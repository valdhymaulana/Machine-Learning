## Supervised Learning

Supervised Learning adalah metode dalam *machine learning* di mana model dilatih menggunakan data yang sudah memiliki label (jawaban yang benar). Setiap data input dipasangkan dengan output yang sesuai, sehingga model dapat mempelajari hubungan antara keduanya. Tujuan utamanya adalah agar model mampu memprediksi atau mengklasifikasikan data baru dengan akurasi yang baik berdasarkan pola yang telah dipelajari.

### Poin-poin Penting
- Menggunakan **data berlabel (labeled data)**
- Terdapat pasangan **input (fitur) dan output (target)**
- Bertujuan untuk **memprediksi hasil pada data baru**
- Terbagi menjadi dua jenis utama:
  - **Regression** → output berupa nilai kontinu (contoh: prediksi harga)
  - **Classification** → output berupa kategori/kelas (contoh: spam atau tidak)
- Model belajar dengan cara **meminimalkan error** antara prediksi dan nilai sebenarnya

### Contoh Algoritma
- Linear Regression  
- Logistic Regression  
- Decision Tree  
- Support Vector Machine (SVM)
